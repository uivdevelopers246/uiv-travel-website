M0 — Bootstrap, CI/CD, environments

Goals: one-repo, preview deploys on every PR, seeded database.
Tasks

Create Next.js app (App Router), TypeScript, ESLint/Prettier, Turborepo optional.

Wire Vercel project: prod + preview; env groups (local/dev/prod).

Supabase project: enable PostGIS, create schemas, seed script.

Add .env management, secret mapping (Vercel env vars ↔ Supabase).

Basic /api/health route & landing page.
Deliverables: live preview links on PRs; npm run db:migrate && db:seed.
Exit: main deploys green; DB + app spin up locally in <5 min.

Time: full-time 2–3 days | 2 devs part-time 1 week.

M1 — Auth & users (RLS foundations)

Goals: secure sign-in, basic profiles, row-level security scaffolding.
Tasks

Supabase Auth (email/password + magic link if you want).

Tables: users, profiles (public minimal view), RLS policies.

Next.js auth context + route guards; /me page edit profile.

Audit fields (created_at, updated_at, by whom) via triggers.
Deliverables: login/signup works; protected pages; profile edit.
Exit: RLS prevents cross-tenant reads; E2E auth test passes.

Time: full-time 3–4 days | 2 devs part-time 1–1.5 weeks.

M2 — Activities catalog (CRUD + uploads)

Goals: operators can create activities with images & metadata.
Tasks

Tables: activities(id, title, price_cents, category, tags[], geom, starts_at/ends_at, status, provider_id).

Supabase Storage buckets + signed URLs; image upload flow.

Admin UI (protected) for create/update/list; public list API.

Indexes: GIST on geom, price/category.
Deliverables: admin CRUD with images; public list/grid.
Exit: CRUD e2e tests; seed data shows on public list.

Time: full-time 1 week | 2 devs part-time 2 weeks.

M3 — Map view & “near me” search

Goals: island map with clustered markers + popups.
Tasks

MapLibre GL + MapTiler/Mapbox tiles; clustering & popups.

API route /api/activities/near?lat&lng&radius_km&max_price.

Optional geocode proxy /api/geo/forward?q= (cache in DB or memory).

Mobile-friendly map/list sync.
Deliverables: Barbados map; click marker → card with CTA.
Exit: p95 <150ms for typical near-me queries on seed data.

Time: full-time 3–4 days | 2 devs part-time ~1 week.

M4 — Booking core (hold → confirm, no payment)

Goals: correct, idempotent booking pipeline w/ no oversells.
Tasks

Tables: timeslots, bookings, unique constraint to prevent double-sell.

Routes: POST /api/bookings/hold (ttl hold), POST /api/bookings/confirm.

Idempotency keys; short transactions; server actions or route handlers.

Cleanup job (cron) for expired holds.
Deliverables: full flow to confirm a booking (free).
Exit: concurrency tests pass (parallel holds resolve correctly).

Time: full-time 1 week | 2 devs part-time 2 weeks.

M5 — Payments & webhook orchestration

Goals: charge, verify, and finalize bookings.
Tasks

Stripe Checkout/PaymentIntents, server-side session creation.

Webhook route (raw body verify) → upsert payment, finalize booking.

Outbox pattern or simple status machine to ensure exactly-once.

Refund/cancel basics; success/cancel pages.
Deliverables: paid, confirmed booking end-to-end.
Exit: replay-safe webhook; E2E test from “select → pay → confirm”.

Time: full-time 1 week | 2 devs part-time 2 weeks.

M6 — Notifications & comms

Goals: transactional emails (confirmation, reminders).
Tasks

Resend (or SMTP) template(s) for confirmation/receipt/reminders.

Cron for reminder sends; bounce/complaint logging (basic).

User email preferences (simple on/off).
Deliverables: branded confirmation mail; reminder 24h before.
Exit: emails observed in sandbox; retry & failure paths logged.

Time: full-time 2–3 days | 2 devs part-time ~1 week.

M7 — AI itinerary (v1 tool)

Goals: natural language → structured search → itinerary list.
Tasks

Define a server “tool”: findActivities({ place, radiusKm, maxPrice, categories }) using PostGIS.

Geocode if place specified; clamp inputs; cache hot results.

Simple itinerary composer (time windows, spacing); optional LLM polish.
Deliverables: “Suggest 5 activities under $200 near Holetown” returns map+list.
Exit: deterministic tool calls; guardrails; telemetry.

Time: full-time 3–4 days | 2 devs part-time ~1 week.
